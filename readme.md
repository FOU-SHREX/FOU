# FOU (V1)

## About
FOU is a watchlist-style portfolio that helps you keep track of your favourite cryptocurrency coins.

## Features
- Add coins
- View your portfolio
- Remove coins
- Save your portfolio
- Automatically load your saved portfolio

## How to Run
- Only Python is required.
- Open the `main.py` file and run the program.

## Current Limitations
- For now, FOU only stores the coin symbols entered by the user.
- It does not check whether a cryptocurrency actually exists, so invalid symbols can still be saved.

## Future Plans
For Version 2, the current plans are:
- Show the current price of coins in the portfolio
- Only accept valid cryptocurrency symbols
